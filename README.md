# 🎮 Dungeon Survivor 2D - Core Prototype

## Descripción
Dungeon Survivor 2D es un videojuego de plataformas 2D desarrollado en Unity y C#. El jugador debe desplazarse por el escenario, saltar, recolectar gemas y combatir enemigos evitando perder toda su vida.

## Objetivo
Implementar las mecánicas principales de un videojuego 2D, incluyendo movimiento, físicas, colisiones, recolección de objetos, combate e interfaz de usuario.

## Controles

- **A / D:** movimiento horizontal.
- **Espacio:** saltar.
- **Z:** atacar, si está configurado.
- **Escape / P:** pausar o reanudar.

## Características

- Movimiento y salto del jugador.
- Detección de suelo mediante colisiones 2D.
- Seguimiento de cámara.
- Efecto de temblor de cámara al recibir un golpe, si está configurado.
- Recolección de gemas y actualización del contador.
- Sistema de vida y daño.
- Combate y derrota de enemigos.
- Menú de pausa y reanudación.

## Tecnologías

- Unity
- C#
- Rigidbody2D
- Collider2D
- Animator
- Unity UI

## Instalación y ejecución

1. Clonar o descargar este repositorio.
2. Abrir Unity Hub.
3. Seleccionar **Add / Open** y elegir la carpeta del proyecto.
4. Abrir la escena principal.
5. Presionar **Play** para ejecutar el videojuego.
